How It Works

The technology behind your outfit recommendations

🤖

Gen AI — Semantic Occasion Resolver

Type your occasion in any language or style ("shaadi", "barat", "office meeting"). The system uses TF-IDF semantic similarity to map your words to the right occasion category — no rigid dropdowns needed.

📊

ML — Content-Based Filtering

Each outfit's occasion tags are vectorized using TF-IDF and compared to your target occasion via cosine similarity (scikit-learn). Only the most relevant garments are shortlisted.

🧠

Deep Learning — Neural Compatibility Scorer

A custom 3-layer feedforward neural network (built in NumPy) scores each upper-lower outfit pair. It combines occasion match, colour harmony, and style coherence into a single compatibility score.

🎨

Color Intelligence

The engine analyses the dominant colour of each uploaded image using pixel-level ML extraction (PIL + NumPy), then applies colour harmony rules to score pair compatibility.

👗

2D Avatar Try-On

The avatar auto-detects its own body region dimensions using JavaScript and precisely layers your outfit images onto the correct body segments — torso, arms, and lower body — in real time.

⚡

Ensemble Scoring

Final score = 35% DL neural + 30% ML cosine + 20% colour harmony + 15% style coherence. The weighted ensemble ensures balanced, fashion-aware recommendations.
